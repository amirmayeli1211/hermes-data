# اتاق ۱۳ — بازی ترسناک پیکسلی

یک بازی ترسناک داستانی در مرورگر. نقشه، داستان، صدا و گرافیک همه داخل همین پوشه‌اند.

## سریع‌ترین راه

فایل `dist/room13.html` را با مرورگر باز کن. تمام.

هیچ نصبی لازم نیست، هیچ سروری لازم نیست، حتی **به اینترنت هم نیاز ندارد** —
صداها و کدها داخل خود همان یک فایل هستند.

## کنترل‌ها

| کلید | کار |
| --- | --- |
| `W A S D` یا کلیدهای جهت‌دار | حرکت |
| `E` یا `Enter` | بررسی / برداشتن / حرف زدن |
| `F` | چراغ‌قوه (باتری مصرف می‌کند) |
| `I` یا `Tab` | کیف و یادداشت‌ها |
| `M` | قطع و وصل صدا |
| `Esc` | بستن پنجره‌ها |

روی موبایل: دکمه‌های روی صفحه.

## چطور بازی کنم

از راهرو شروع می‌کنی. یادداشت‌ها را بخوان و اتاق‌ها را بگرد.

سه چیز لازم داری:
- **کلید آهنی** — کشوی میز در اتاق خواب
- **کلید استخوانی** — میز کار در اتاق کار
- **نوار کاست** — جعبه اسباب‌بازی در اتاق کودک

و مهم‌تر: **«راه بستن»** را در قفسهٔ اتاق کار پیدا کن. بدون خواندنش، پایان خوب
باز نمی‌شود.

| پایان | چطور |
| --- | --- |
| **بستن** (بهترین) | نوار + راه بستن را داشته باش، بعد آیین را انجام بده |
| **فرار** | برگرد و فرار کن — زنده می‌مانی، ولی تمام نمی‌شود |
| **پایان بد** | جواب بده |
| **گرفته شدن** | آن موجود به تو برسد |

## نکتهٔ بازی

چراغ‌قوه هم دوستت است هم دشمنت: با آن می‌بینی، و با آن **دیده می‌شوی**.
موجود وقتی چراغ روشن است و نزدیک باشی شکار می‌کند. اگر چراغ را خاموش کنی
عقب می‌کشد — ولی آن‌وقت تقریباً هیچ نمی‌بینی.

## صداها

هر ۱۳ صدا با `ffmpeg` از نویز و نوسان‌ساز ساخته شده‌اند، نه دانلود شده.
هیچ فایل صوتی از جایی گرفته نشده، پس هیچ مسئلهٔ مجوزی هم ندارد.

بازتولید همه‌شان:

```sh
sh tools/generate-audio.sh
```

## تست‌ها

| دستور | چه چیزی را چک می‌کند |
| --- | --- |
| `node tools/validate-world.js` | نقشه: دسترسی همهٔ اتاق‌ها، نبود soft-lock، ترتیب درست کلیدها |
| `node tools/validate-story.js` | داستان: گره‌های بی‌پایان، شاخه‌های شکسته، همهٔ پایان‌ها |
| `node tools/playtest.js` | بازی واقعی در مرورگر واقعی — ۴۶ تست |
| `node tools/package.js` | ساخت مجدد `dist/` |
| `python3 tools/verify-package.py` | بستهٔ ساخته‌شده کامل و سالم است |

## منابع داستان

پس‌زمینه از **فولکلور واقعی ایرانی** گرفته شده:

- **آل** — موجودی که در باور مردم ایران، افغانستان و آسیای مرکزی سراغ نوزادان
  و مادرانشان می‌آید. توصیف سنتی‌اش: زنی با پاهای **برعکس** — یعنی همیشه
  پشت سرت است، حتی وقتی مطمئنی تنهایی.
- **بختک** — همان فلج خواب. توصیفش همیشه یکی است: وزنéای روی سینه که
  نمی‌گذارد تکان بخوری.
- **جایگزینی به‌جای کشتن** — در باور به جن‌زدگی، موجود *جای* کسی می‌نشیند،
  نابودش نمی‌کند.

خانه، خانواده و اتفاقات داستان **ساختگی**‌اند. باورها واقعی‌اند، و یادداشت‌های
داخل بازی می‌گویند هر جزئیات از کدام باور آمده. هیچ اتفاق واقعی‌ای ادعا نشده.

## ساختار پروژه

```
index.html            صفحهٔ اصلی (نسخهٔ چندفایلی)
style.css             ظاهر
js/sprites.js         گرافیک پیکسلی — کاراکترها شبکه‌های حرفی
js/audio.js           موتور صدا، با تحمل خطا
js/world.js           نقشه: ۱۰ اتاق، ۱۱ در، ۴۲ شیء + اعتبارسنجی
js/story.js           داستان: ۳۳ گره، ۱۰۱ خط، ۲۴ نقطهٔ ورود، ۳ پایان
js/game.js            موتور: حلقه، برخورد، نور، موجود، رابط
tools/                ساخت صدا، اعتبارسنجی، تست مرورگر، بسته‌بندی
assets/audio/         ۱۳ فایل mp3 (~۶۵۰ کیلوبایت)
dist/                 خروجی‌های آماده
```
